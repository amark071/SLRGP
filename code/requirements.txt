# Important environment boundaries
# --------------------------------
# 1. `experiments/exp2_operator_learnability/ranking/s2d_specter2.py` imports
#    `adapters`. The inspected server has adapters==1.3.0, which declares
#    transformers~=4.57.6 and is incompatible with the transformers==4.47.1
#    environment recorded above. Run that one-off SPECTER2 analysis in a
#    separate environment.
#

#    vLLM. The inspected server has vllm==0.24.0, which requires

#    by the dependencies above.

#    `libnvJitLink.so.13`; configure the CUDA 13 runtime/library path before
#    relying on 4-bit GPU inference.
